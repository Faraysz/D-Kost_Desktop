# 🏠 D-Kost Desktop Application

D-Kost Desktop adalah aplikasi **desktop berbasis Java** yang digunakan untuk membantu pengelolaan data kos secara sederhana dan terstruktur.  
Aplikasi ini dikembangkan sebagai **project perkuliahan Semester 1 dan 2**, dengan tujuan melatih pemahaman **Java OOP** dan pembuatan **GUI Desktop**.

---

## ✨ Fitur Utama
- 🔐 Login Multi Role (Admin & Pemilik)
- 👤 Manajemen Data Penghuni Kos
- 🛏️ Manajemen Informasi Kamar
- 💰 Pencatatan dan Manajemen Data Transaksi
- 📊 Tampilan Menu sesuai Hak Akses User
- 🖥️ Antarmuka Desktop berbasis GUI

---

## 🛠️ Teknologi yang Digunakan
- **Java**
- **Java Swing (GUI Desktop)**
- **NetBeans IDE**
- **Object-Oriented Programming (OOP)**

---

## 📂 Struktur Program
Beberapa file utama dalam project ini:
- `Login.java` – Halaman login user
- `MenuAdmin.java` – Menu khusus Admin
- `MenuPemilik.java` – Menu khusus Pemilik
- `DataPenghuni.java` – Manajemen data penghuni kos
- `InfoKamar.java` – Informasi dan data kamar
- `DataTransaksi.java` – Pencatatan transaksi
- `Config.java` – Konfigurasi aplikasi
- `User.java` – Model user

---

## 🎯 Tujuan Project
Project ini dibuat untuk:
- Memahami dasar **pemrograman Java**
- Mengimplementasikan konsep **OOP**
- Membuat aplikasi **Desktop GUI**
- Simulasi sistem manajemen kos
